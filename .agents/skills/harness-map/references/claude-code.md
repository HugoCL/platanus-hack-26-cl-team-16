# Claude Code

From this repo root run `node scripts/skills/link.mjs` to expose the installed skills under `.claude/skills/`. Claude Code documents per-skill directory symlinks. A symlink for the entire `.claude/skills/` directory is **UNCONFIRMED**. Use real parent directories and per-skill links. Read repo instructions in `CLAUDE.md` when present. pstack's Claude model rule is `~/.claude/rules/pstack-models.md`. [Skill discovery](https://code.claude.com/docs/en/skills.md), [pstack mapping](../../../docs/harness/claude-code.md)

- **Models and workers.** Select from the aliases in the live `Agent` schema. For example, `Agent({ description: "Review the patch", prompt, model: "opus", effort: "high" })`, with `effort` when the schema offers it. Per-call model wins over subagent frontmatter, `CLAUDE_CODE_SUBAGENT_MODEL`, and the parent model, in that order. Use `Explore` for read-only review where appropriate and brief it to avoid writes. A Claude alias cannot fill a GPT Sol seat.
- **Results and questions.** Collect a foreground result or the background completion notification. Use `AskUserQuestion({ questions: [...] })` if present. In print mode or when absent, put the question in the final reply.
- **PRs and issues.** Use the active forge tools or `gh`. Run the [vendored waiter](../../babysit-pr/scripts/pr-wait) with `Monitor` when offered, otherwise as one command.
- **pstack agents.** The pstack adapter names `pstack:poteto-agent` and `pstack:comment-sicko`. Those names exist only when the pstack plugin is installed, so with just `pnpm skills:link` they do not resolve. Translate each into a native call: read the definition in `.agents/agents/<name>.md`, put its body and the task in the `Agent` prompt, use `subagent_type: "general-purpose"`, and pass `model` and `effort` yourself from [subagent routing](../../subagent-routing/SKILL.md). The file's `model:` line holds a Cursor slug, so never pass it on. This repo does not link `.agents/agents/` into `.claude/agents/`: a project agent registers under its frontmatter name without the `pstack:` prefix, and how Claude Code treats that slug is **UNCONFIRMED**. Copying the two files there by hand is a local choice.
